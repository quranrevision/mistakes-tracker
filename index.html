Surahs

Per page is the score divided by the surah’s length in pages, so long and short surahs can be compared fairly. Surahs shorter than a page are marked “short”, because a single mistake moves them a lot. Tap a surah to open it.

Erasing a highlight within 20 minutes removes it completely, as a quick correction. Erasing it later keeps it in these stats as a fixed mistake.

The eraser removes only the top highlight when several are stacked on the same mistake. Tap again to remove the next one down. Removing a repeat while an earlier highlight still marks the mistake does not count as fixing it.

Highlighting over an existing highlight marks the same mistake again, so they count as one “repeated” mistake. It counts in Last 30 days or Last 7 days if you re-marked it then, and it is worth the highest colour value among its highlights.

Colour values and order

Drag the handle on the left to change the order of colours on the bottom bar. The numbers set how much each highlight colour counts towards the score. Decimals work, for example 0.5 for a hesitation and 1 for a real mistake. Type a value or use − and +. Set a colour to 0 to leave it out.

Change a colour everywhere

Switch every highlight of one colour to another, on all pages and in your fixed mistakes. Dates are kept, so nothing is counted as new or fixed.
