Surahs

Per page is the score divided by the surah’s length in pages, so long and short surahs can be compared fairly. Surahs shorter than a page are marked “short”, because a single mistake moves them a lot. Tap a surah to open it.

Erasing a highlight within 20 minutes removes it completely, as a quick correction. Erasing it later keeps it in these stats as a fixed mistake.

Colour values

How much each highlight colour counts towards the score. Decimals work, for example 0.5 for a hesitation and 1 for a real mistake. Type a value or use − and +. Set a colour to 0 to leave it out.
